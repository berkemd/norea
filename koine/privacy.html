Koine — Privacy

Koine collects nothing. Not because we choose not to look, but because there is nowhere for anything to go: the app makes no network requests at all.

What is collected

Nothing. No account, no sign-in, no analytics, no crash reporting, no advertising identifier and no third-party SDK of any kind.

What permissions are requested

None. Koine asks for no camera, no microphone, no photo library, no location. Its Info.plist contains no usage-description strings, and a build gate fails the build if one is ever added — because adding one would mean this page had become untrue.

What is stored on your device

Your answers: which word, when, and whether you got it right. They live in a file in the app's own container and are never transmitted, because there is no transmission. One setting is stored too: whether proper names are counted as recognisable.

Where the corpus comes from

The frequency list is derived by us from Tatoeba's sentence exports (CC BY 2.0 FR) and ships inside the app. Nothing is fetched at runtime; the attribution is shown on screen, as that licence requires.

How this is verified

Every build runs a check across the whole source tree — with comments stripped, so it measures code rather than prose — for URLSession, NWConnection, CFNetwork, URLRequest, StoreKit and CLLocationManager. If any appears, the build fails. Writing a promise is not keeping it; this one is measured.

Children

Koine is rated 4+ and is suitable for children. Since it collects nothing and transmits nothing, it collects nothing from children either.

Changes

If a future version ever needed a network connection, this page would change first and the build gate would change with it. That order is deliberate.
