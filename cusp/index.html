Cusp

Start, finish, or let go.

Most task apps give you two states: not done, and done. That is not how work actually ends. A great deal of it is neither finished nor forgotten — it just sits, quietly, for months, being neither.

Cusp has four lanes, and the fourth is the point.

CuspNamed, not started. Everything begins here.
DoingYou have actually picked it up.
DoneFinished.
ReleasedDeliberately let go. Not failed, not deleted — decided.

Releasing is a first-class action, not a delete. The thread stays, with the date you let it go. A list you are allowed to abandon is a list you can trust.

The Sunday glance

Once a week Cusp shows you one short panel: the threads that have been sitting on the cusp the longest, with how many days each has been there. No badge, no streak, no notification pressure. Just the number, once, so the decision to start it or release it is yours and conscious.

Your work in plain files

Pick a folder — iCloud Drive, or any Files location. Cusp mirrors every thread there as a plain Markdown file, and every state change as one append-only .jsonl file per day. You can read it with anything. You can grep it. If Cusp disappeared tomorrow, your record would not.
