Common questions

I linked a folder and Vird says it sees no notes.

Vird looks for a NEUMA vault: a folder containing vault.json. If you picked the parent folder by mistake, re-pick and choose the folder that has that file directly inside it.

Where do my cards live?

Your library is stored on the device. Local mirroring is included in the free plan. On iOS it writes Markdown and JSONL files to the app's Documents/vird folder, visible in Files. A local mirror is not an independent backup. Before deleting Vird, export your library as JSON and save the file outside the app. Do not assume automatic iCloud sync is enabled.

How can I try the starter cards?

Download the three-card CSV, then use CSV import on the New tab when the app is available. Vird accepts front/back columns in CSV or supported tab-separated text. It does not import Anki .apkg packages; native export is JSON.

I turned on AI suggestions and nothing happened.

Three things have to be true at once: Plus is active, a provider key is stored, and the note has a title and an excerpt. If a request fails, Vird falls back to the on-device extraction silently rather than showing you an error in the middle of a study session — check the badge under the candidate list to see which path produced it.

What exactly leaves my device when AI is on?

The note's title and a short excerpt. Not the body, not tags, not the file path, not anything from other notes. This is enforced in one place in the code and tested; see the Privacy page.

How do I restore Plus on a new phone?

Self → Restore purchases. It uses your App Store account; there is nothing to log into.

A card is wrong or embarrassing.

Long-press it in the library and delete. Deleting a card does not touch the note it came from.

Reporting something broken

If Vird loses data, please tell me before anything else and include the day and roughly the time — the review log is append-only and I can usually work out what happened.
